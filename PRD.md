# 🍽️ Restaurant POS System — PRD

## 📌 Product Overview

This system is a complete restaurant management platform that includes:

* POS (Billing)
* Table Management
* Kitchen Display System (KDS)
* Order Management
* QR Ordering System
* Staff Management

The goal is to streamline restaurant operations in real-time.

---

## 🎯 Objectives

* Fast order processing
* Real-time kitchen coordination
* Reduce manual work
* Improve billing accuracy
* Enable automation via QR ordering

---

## 👥 User Roles

### 1. Admin

* Full system access
* Manage staff, menu, reports, settings

### 2. Manager

* Handle daily operations
* Monitor orders, tables, kitchen

### 3. Waiter

* Manage tables
* Take and send orders

### 4. Chef

* View kitchen orders
* Update cooking status

### 5. Cashier

* Handle billing and payments

---

## 📦 Core Modules

### 1. Dashboard

* Revenue
* Orders count
* Active tables
* Alerts

### 2. Table Management

* Table status (Available / Occupied / Reserved)
* Open table
* Add items
* Generate bill

### 3. POS System

* Menu display
* Add items to cart
* Apply tax
* Generate bill
* Payment handling

### 4. Kitchen Display (KDS)

* Show orders
* Update status:

  * Pending
  * Cooking
  * Ready

### 5. Order Management

* Track all orders
* Status flow:
  New → Preparing → Ready → Delivered

### 6. QR Ordering

* Customer scans QR
* Orders directly from menu
* Sends to kitchen

### 7. Staff Management

* Add staff
* Assign roles
* Track shifts

### 8. Billing & Payment

* GST calculation
* Payment modes:

  * Cash
  * Card
  * UPI

---

## 🔄 System Flow

Customer / Waiter

Kitchen (KDS)
